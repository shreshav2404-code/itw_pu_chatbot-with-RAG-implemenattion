# Presidency University website crawl

This folder contains a source-linked crawl of the public website at https://presidencyuniversity.in/.

## Files

- `pages.jsonl`: one JSON object per crawled HTML page, with title, URL, description, headings, page text, links, media references, category, and crawl time.
- `chunks.jsonl`: page text split into passages with source URL and heading metadata for a basic text-RAG index.
- `site_link_graph.jsonl.gz`: compressed internal page-to-page links with anchor labels and page categories.
- `media_manifest.jsonl`: image, video, audio, iframe, and source references with page context, alt text, and captions. Binary media is not downloaded.
- `documents_manifest.jsonl`: linked documents and download outcomes. University-domain files up to 50 MB are downloaded under `documents/`.
- `documents_text.jsonl`: extracted document text, generated by running `python ..\extract_documents.py` after the crawl.
- `document_chunks.jsonl`: extracted PDF/Office passages with document source URLs and metadata, generated by the same command.
- `RAG_INGESTION_GUIDE.md`: JupyterHub multimodal RAG ingestion notes, source separation, citation metadata, and image/video/audio follow-up steps.
- `sitemap_urls.txt`: all entries in the site's public sitemap at crawl time.
- `crawl_urls.txt`: first-party pages attempted from that sitemap.
- `crawl_failures.json`: URLs that failed or returned non-success status.
- `crawl_summary.json`: counts and crawl scope.
- `FOCUS_GUIDE.md`: source-backed guide to current exam/pass/makeup/promotion rules, fees and assistance, scholarships, course curricula, Launchpad, and campus navigation.
- `focused_chunks.jsonl`: topic-tagged RAG passages from web pages, extracted university documents, the uploaded PDF, DSpace item metadata, and virtual-tour labels.
- `priority_pages.jsonl`: source pointers for academic-regulation, examination, calendar, fee, scholarship, Launchpad, course, and timetable pages.
- `unindexed_first_party_pages.txt`: internal page paths discovered through site links but missing from the published sitemap.
- `unindexed_crawl_summary.json` and `unindexed_crawl_failures.json`: outcome for those additional paths.
- `all_crawl_failures.json`: combined sitemap and link-discovery failures.

## Notes and limitations

The crawler preserves source URLs and page context. Re-crawl to refresh notices, timetables, calendars, events, and other changing information. Check each source page's publication/effective date before answering time-sensitive questions. Media references are pointers for a later OCR, speech-to-text, or video-frame pipeline; this crawl does not transcribe video/audio or perform OCR over images. Some links use external systems (admissions, learning systems, library, YouTube, etc.) and are inventoried as links rather than crawled. The public website may describe campus facilities, but it may not publish building floor plans or room-by-room directions; do not infer physical wayfinding where no source exists.

This is a practical crawl of the public sitemap and linked documents, not a guarantee that authenticated, dynamically generated, blocked, or unindexed site content has been captured. 758 downloaded files yielded no extractable text; these may be image-only scans or unsupported formats and remain listed in `documents_text.jsonl` and the original documents manifest. Review downloaded files and their reuse terms before redistributing them.
